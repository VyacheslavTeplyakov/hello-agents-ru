## Рисунок 2.3 — Общая архитектура экспертных систем

```mermaid
graph LR
    DE["👨‍🔬 Эксперт<br/>предметной области"]
    KE["🧑‍💻 Инженер<br/>по знаниям"]
    KB["📚 База знаний<br/>(правила ЕСЛИ–ТО)"]
    IE["⚙️ Механизм<br/>вывода"]
    UI["🖥️ Интерфейс<br/>пользователя"]
    USER["👤 Пользователь"]

    DE -->|"знания"| KE
    KE -->|"кодирование"| KB
    KB <-->|"поиск / обновление"| IE
    IE <-->|"запросы / ответы"| UI
    UI <-->|"диалог"| USER
```

## Рисунок 2.4 — Обратная цепочка рассуждений MYCIN

```mermaid
flowchart TD
    GOAL["🎯 Цель: определить возбудителя"]

    GOAL --> SG1["Подцель А:<br/>признаки воспаления?"]
    GOAL --> SG2["Подцель Б:<br/>результаты анализов?"]

    SG1 --> Q1["❓ Вопрос врачу:<br/>температура?"]
    SG1 --> Q2["❓ Вопрос врачу:<br/>кашель?"]
    SG2 --> Q3["❓ Вопрос врачу:<br/>результат посева?"]

    Q1 --> F1["✅ Факт: 38.5 °C"]
    Q2 --> F2["✅ Факт: есть кашель"]
    Q3 --> F3["✅ Факт: посев положителен"]

    F1 & F2 & F3 --> CF["📊 Коэффициент<br/>достоверности (КД)"]
    CF --> DX["💊 Диагноз +<br/>рекомендация антибиотика"]
```

## Рисунок 2.6 — Иерархия агентов при строительстве башни («Общество разума»)

graph TD

    FB["FIND-BLOCK<br/>(найти блок)"]
    GB["GET-BLOCK<br/>(взять блок)"]

    BU -->|"повторять"| AB
    AB --> FB
    AB --> GB
    AB --> PT
    GB --> SS
    GB --> RE
    GB --> GR

## Рисунок 2.7 — Символизм vs Коннекционизм

```mermaid
flowchart LR
    subgraph SYM["Символизм — нисходящий подход"]
        direction TB
        EX["👨‍🔬 Эксперт<br/>(вручную)"]
        RU["📋 Явные правила<br/>(база знаний)"]
        IN["⚙️ Механизм вывода"]
        R1["✅ Решение"]
        EX --> RU --> IN --> R1
    end

    subgraph CON["Коннекционизм — восходящий подход"]
        direction TB
        DA["📊 Обучающие данные"]
        NN["🧠 Нейронная сеть<br/>(веса связей)"]
        BP["🔄 Обратное распространение<br/>(корректировка весов)"]
        R2["✅ Решение"]
        DA --> NN --> R2
        R2 -->|"ошибка"| BP --> NN
    end
```

## Рисунок 2.9 — Парадигма «предобучение → дообучение»

```mermaid
flowchart LR
    DATA["📚 Общий корпус<br/>(интернет-масштаб)"]
    SSL["Самоконтролируемое<br/>обучение<br/>(предсказание слова)"]
    FM["🧠 Базовая модель<br/>(Foundation Model)"]

    FT1["Дообучение<br/>на задаче 1"]
    FT2["Дообучение<br/>на задаче 2"]
    FTN["Дообучение<br/>на задаче N"]

    T1["📌 Анализ<br/>тональности"]
    T2["🔤 Машинный<br/>перевод"]
    TN["❓ Ответы на<br/>вопросы"]

    DATA --> SSL --> FM
    FM --> FT1 --> T1
    FM --> FT2 --> T2
    FM --> FTN --> TN
```

## Рисунок 2.10 — Архитектура ключевых компонентов LLM-агента

```mermaid
flowchart TD
    ENV["🌍 Среда"]
    PERC["📡 Модуль восприятия<br/>(сенсоры)"]
    OBS["👁️ Наблюдения"]
    PLAN["📋 Модуль планирования<br/>(рефлексия / самокритика)"]
    LLM["🧠 БЯМ / LLM<br/>(рассуждение и решение)"]
    MEM["💾 Память<br/>(история взаимодействий)"]
    EXEC["⚙️ Модуль исполнения"]
    TOOLS["🛠️ Инструменты<br/>(API / код / поиск)"]

    ENV -->|"сырой ввод"| PERC
    PERC --> OBS
    OBS --> PLAN
    PLAN -->|"инструкции"| LLM
    LLM <-->|"обновление / запрос"| MEM
    LLM -->|"вызов инструмента"| EXEC
    EXEC --> TOOLS
    TOOLS -->|"результат инструмента"| LLM
    TOOLS -->|"изменение состояния"| ENV

    style LLM fill:#fef9c3,stroke:#ca8a04
    style MEM fill:#f3e8ff,stroke:#9333ea
    style TOOLS fill:#fee2e2,stroke:#ef4444
```
