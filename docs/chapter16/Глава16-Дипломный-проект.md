## 16.1 Смысл дипломного проекта

### 16.1.1 Зачем делать дипломный проект

Лучший способ изучить технологию — не читать туториалы, а **практиковаться**. Пройдя предыдущие главы, вы уже освоили теоретические знания и инструменты для построения агентных систем. Однако настоящий вызов состоит в другом: **как применить эти знания к реальным задачам? Как спроектировать законченную систему? Как обрабатывать граничные случаи и исключения?**

Ключевая ценность дипломного проекта — развитие комплексных прикладных навыков: вы избирательно интегрируете в один цельный проект всё, что изучили ранее (парадигмы агентов, систему инструментов, механизмы памяти, коммуникационные протоколы и т. д.).

По итогам этой главы вы сможете самостоятельно спроектировать и реализовать полноценное агентное приложение, уверенно использовать возможности фреймворка HelloAgents, освоить базовые операции Git и GitHub, научиться писать чёткую проектную документацию, участвовать в совместной разработке открытого кода и в итоге получите технический проект, достойный портфолио.

### 16.1.2 Форма дипломного проекта

Ваш дипломный проект будет представлен в форме **открытого проекта**, размещённого в репозитории совместного творчества Hello-Agents (директория `Co-creation-projects`). Конкретные требования:

1. **Именование проекта**: формат `{ваш_GitHub_логин}-{название_проекта}`, например `jjyaoao-CodeReviewAgent`.

2. **Состав проекта**:
   - Запускаемый Jupyter Notebook (`.ipynb`) или Python-скрипт
   - Полный список зависимостей (`requirements.txt`)
   - Чёткая документация (`README.md`)
   - Опционально: демонстрационное видео, скриншоты, датасеты и т. п.

3. **Способ сдачи**: через Pull Request на GitHub.

4. **Процесс проверки**: участники сообщества проведут код-ревью, предложат улучшения; после одобрения проект будет слит в основной репозиторий.

## 16.2 Руководство по выбору темы

### 16.2.1 Принципы выбора темы

Хороший дипломный проект должен быть практичным — решать настоящую проблему, а не демонстрировать технологию ради самой технологии. Нужно стремиться к реализуемости в разумные сроки при имеющихся ресурсах и к тому, чтобы проект ясно показывал ваши технические возможности.

### 16.2.2 Рекомендуемые направления

Ниже приведены несколько возможных направлений — можно выбрать одно из них или предложить собственную идею.

**(1) Инструменты повышения продуктивности**

- **Интеллектуальный ассистент код-ревью**: автоматически анализирует качество кода, выявляет потенциальные баги, предлагает улучшения.
- **Интеллектуальный генератор документации**: создаёт API-документацию и руководства пользователя на основе кода.
- **Интеллектуальный помощник для встреч**: фиксирует содержание совещаний, генерирует протоколы, выделяет задачи.
- **Интеллектуальный почтовый ассистент**: автоматически классифицирует письма, формирует черновики ответов, напоминает о важных событиях.

**(2) Учебные ассистенты**

- **Интеллектуальный партнёр по обучению**: рекомендует ресурсы по текущему прогрессу, генерирует упражнения, отвечает на вопросы.
- **Интеллектуальный помощник с научными статьями**: помогает искать литературу, резюмирует работы, оформляет цитаты.
- **Интеллектуальный наставник по программированию**: предоставляет упражнения, проводит код-ревью, составляет учебные маршруты.
- **Интеллектуальный помощник по языкам**: практика диалога, исправление грамматики, расширение словарного запаса.

**(3) Творчество и развлечения**

- **Интеллектуальный генератор историй**: создаёт романы, сценарии и стихи по пользовательским вводам.
- **Интеллектуальный NPC для игр**: персонажи с характером, способные естественно общаться с игроком.
- **Интеллектуальные рекомендации музыки**: подбор треков по настроению и ситуации, формирование плейлистов.
- **Интеллектуальный помощник с рецептами**: подбор блюд по ингредиентам и вкусовым предпочтениям, генерация списка покупок.

**(4) Анализ данных**

- **Интеллектуальный аналитик данных**: автоматически анализирует данные, строит визуализации, пишет аналитические отчёты.
- **Интеллектуальный анализ акций**: анализ биржевых данных и новостного фона, инвестиционные рекомендации.
- **Интеллектуальный мониторинг общественного мнения**: отслеживает соцсети и новостные сайты, анализирует тенденции.
- **Интеллектуальный анализ конкурентов**: сбор данных о конкурентах, сравнительный анализ, формирование отчётов.

**(5) Бытовые сервисы**

- **Интеллектуальный помощник по здоровью**: записывает показатели здоровья, даёт рекомендации, составляет планы тренировок.
- **Интеллектуальный финансовый помощник**: ведёт учёт доходов и расходов, анализирует траты, советует по управлению финансами.
- **Интеллектуальный помощник по покупкам**: сравнивает цены, рекомендует товары, составляет списки покупок.
- **Управление умным домом**: управление устройствами умного дома через естественный язык.

### 16.2.3 Пример выбора темы

Рассмотрим конкретный пример: как выбрать тему и спроектировать проект.

**Название проекта**: интеллектуальный ассистент код-ревью (CodeReviewAgent)

**Анализ проблемы**: код-ревью — важный этап разработки программного обеспечения, но ручная проверка занимает много времени и легко упускает проблемы. Существующие инструменты статического анализа умеют находить лишь синтаксические ошибки и не понимают логику кода, поэтому нужен интеллектуальный ассистент, способный разбираться в семантике кода и проводить глубокий анализ.

**Ключевые функции**: в рамках проекта будут реализованы анализ качества кода (стиль, соглашения об именовании, полнота комментариев), обнаружение потенциальных багов (логические ошибки, граничные условия, утечки ресурсов), рекомендации по оптимизации производительности (узкие места, варианты улучшения), поиск уязвимостей безопасности (SQL-инъекции, XSS и другие), а также рекомендации по лучшим практикам.

**Ожидаемый результат**: запускаемый Jupyter Notebook с демонстрацией полного процесса ревью; поддержка Python, JavaScript и других популярных языков; генерация структурированного отчёта в формате Markdown с конкретными примерами кода и предложениями по улучшению.

**Основной фрагмент кода (main.ipynb)**

```python
# ========================================
# Интеллектуальный ассистент код-ревью
# ========================================

from hello_agents import SimpleAgent, HelloAgentsLLM, ToolRegistry
from hello_agents.tools import Tool, ToolParameter
from typing import Dict, Any, List
import ast
import os

# ========================================
# 0. Настройка параметров LLM
# ========================================

os.environ["LLM_MODEL_ID"] = "Qwen/Qwen2.5-72B-Instruct"
os.environ["LLM_API_KEY"] = "your_api_key_here"
os.environ["LLM_BASE_URL"] = "https://api-inference.modelscope.cn/v1/"
os.environ["LLM_TIMEOUT"] = "60"

# ========================================
# 1. Определение инструментов анализа кода
# ========================================

class CodeAnalysisTool(Tool):
    """Инструмент статического анализа кода"""

    def __init__(self):
        super().__init__(
            name="code_analysis",
            description="Анализирует структуру, сложность и потенциальные проблемы Python-кода"
        )

    def run(self, parameters: Dict[str, Any]) -> str:
        """Анализирует код и возвращает результат"""
        code = parameters.get("code", "")
        if not code:
            return "Ошибка: код не может быть пустым"

        try:
            tree = ast.parse(code)
            functions = [node for node in ast.walk(tree)
                        if isinstance(node, ast.FunctionDef)]
            classes = [node for node in ast.walk(tree)
                      if isinstance(node, ast.ClassDef)]

            result = {
                "Количество функций": len(functions),
                "Количество классов": len(classes),
                "Строк кода": len(code.split('\n')),
                "Список функций": [f.name for f in functions],
                "Список классов": [c.name for c in classes]
            }
            return str(result)
        except SyntaxError as e:
            return f"Синтаксическая ошибка: {str(e)}"

    def get_parameters(self) -> List[ToolParameter]:
        return [
            ToolParameter(
                name="code",
                type="string",
                description="Python-код для анализа",
                required=True
            )
        ]

class StyleCheckTool(Tool):
    """Инструмент проверки стиля кода"""

    def __init__(self):
        super().__init__(
            name="style_check",
            description="Проверяет соответствие кода стандарту PEP 8"
        )

    def run(self, parameters: Dict[str, Any]) -> str:
        """Проверяет стиль кода"""
        code = parameters.get("code", "")
        if not code:
            return "Ошибка: код не может быть пустым"

        issues = []
        lines = code.split('\n')
        for i, line in enumerate(lines, 1):
            if len(line) > 79:
                issues.append(f"Строка {i}: превышение 79 символов")
            if line.startswith(' ') and not line.startswith('    '):
                if len(line) - len(line.lstrip()) not in [0, 4, 8, 12]:
                    issues.append(f"Строка {i}: неправильный отступ")

        if not issues:
            return "Стиль кода хороший, соответствует стандарту PEP 8"
        return "Обнаружены следующие проблемы:\n" + "\n".join(issues)

    def get_parameters(self) -> List[ToolParameter]:
        return [
            ToolParameter(
                name="code",
                type="string",
                description="Python-код для проверки",
                required=True
            )
        ]

# ========================================
# 2. Создание реестра инструментов и агента
# ========================================

# Создаём реестр инструментов
tool_registry = ToolRegistry()
tool_registry.register_tool(CodeAnalysisTool())
tool_registry.register_tool(StyleCheckTool())

# Инициализируем LLM
llm = HelloAgentsLLM()

# Определяем системный промпт
system_prompt = """Вы — опытный эксперт по код-ревью. Ваша задача:

1. Использовать инструмент code_analysis для анализа структуры кода
2. Использовать инструмент style_check для проверки стиля кода
3. На основе результатов анализа предоставить подробный отчёт о проверке

Отчёт должен включать:
- Анализ структуры кода
- Проблемы со стилем
- Потенциальные баги
- Рекомендации по оптимизации производительности
- Рекомендации по лучшим практикам

Выводите отчёт в формате Markdown."""

# Создаём агента
agent = SimpleAgent(
    name="Ассистент код-ревью",
    llm=llm,
    system_prompt=system_prompt,
    tool_registry=tool_registry
)

# ========================================
# 3. Запуск примера
# ========================================

# Читаем пример кода
with open("data/sample_code.py", "r", encoding="utf-8") as f:
    sample_code = f.read()

print("=== Код для проверки ===")
print(sample_code)
print("\n" + "="*50 + "\n")

# Выполняем код-ревью
print("=== Начинаем код-ревью ===")
review_result = agent.run(f"Пожалуйста, проверьте следующий Python-код:\n\n```python\n{sample_code}\n```")

print(review_result)

# Сохраняем отчёт о ревью
with open("outputs/review_report.md", "w", encoding="utf-8") as f:
    f.write(review_result)

print("\nОтчёт сохранён в outputs/review_report.md")
```
