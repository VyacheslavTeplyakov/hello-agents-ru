# Правила работы с проектом hello-agents

## Структура перевода

Книга переводится на русский язык. Готовые переводы глав лежат в `docs/chapterN/`, примеры кода — в `code-ru/chapterN/`.

## Обязательное правило: перевод кода параллельно с главой

**При работе над любой новой главой:**

1. Основной агент переводит текст главы (`docs/chapterN/`)
2. **Немедленно** после начала перевода главы — запустить субагента в фоне (`run_in_background: true`) с помощью скилла `translate-book-code-ru` для адаптации примеров кода из `code/chapterN/` в `code-ru/chapterN/`

**Никогда не завершать перевод главы без соответствующего `code-ru/chapterN/`.**

## Инструкция по переводу кода

Детали — в скилле `translate-book-code-ru`:
- Переводить: комментарии, строки `print()`/сообщения об ошибках, локали (`cn` → `ru`)
- НЕ переводить: имена функций/классов, импорты, ключи словарей, пути к файлам
- Переводить все типы файлов: `.py`, `.ipynb`, `.json`, `.yaml`, `.md`
- Бинарные/zip файлы копировать как есть
