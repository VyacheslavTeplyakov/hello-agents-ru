# Кибер-городок — FastAPI бэкенд

Бэкенд-сервис системы диалогов с ИИ-NPC на основе фреймворка HelloAgents.

## Возможности

### Ключевые функции
- **Диалоги один-на-один с NPC**: игрок общается с NPC в реальном времени, обработкой занимается отдельный агент
- **Пакетная генерация диалогов**: периодическая массовая генерация самостоятельных реплик всех NPC снижает стоимость API на 66%
- **Менеджер состояний**: автоматически обновляет и кэширует состояния NPC
- **Поддержка CORS**: поддерживает кросс-доменный доступ для HTML5-экспорта Godot

### Персонажи NPC
1. **Иван** — Python-инженер (рабочая зона)
2. **Пётр** — продакт-менеджер (переговорная)
3. **Сергей** — UI-дизайнер (зона отдыха)


## Эндпоинты API

### 1. Получение списка NPC
```http
GET /npcs
```

Пример ответа:
```json
{
  "npcs": [
    {
      "name": "Иван",
      "title": "Python-инженер",
      "location": "рабочая зона",
      "activity": "пишет код",
      "available": true
    }
  ],
  "total": 3
}
```

### 2. Диалог с NPC
```http
POST /chat
Content-Type: application/json

{
  "npc_name": "Иван",
  "message": "Привет, чем ты занимаешься?"
}
```

Пример ответа:
```json
{
  "npc_name": "Иван",
  "npc_title": "Python-инженер",
  "message": "Привет! Я как раз оптимизирую мультиагентную систему, очень интересно.",
  "success": true,
  "timestamp": "2024-01-15T10:30:00"
}
```

### 3. Получение статусов NPC
```http
GET /npcs/status
```

Пример ответа:
```json
{
  "dialogues": {
    "Иван": "Наконец-то починил этот баг, тесты проходят!",
    "Пётр": "Надо подготовить материалы к продуктовому ревью на следующей неделе.",
    "Сергей": "Цветовая палитра неплохо смотрится, нужно подкрутить детали."
  },
  "last_update": "2024-01-15T10:30:00",
  "next_update_in": 25
}
```

### 4. Принудительное обновление статусов
```http
POST /npcs/status/refresh
```

## Основной дизайн

### Пакетная генерация диалогов
Чтобы снизить стоимость API и задержки, применяется стратегия пакетной генерации:

**Традиционный подход:**
- 3 NPC × раз в 30 секунд = 6 вызовов API в минуту
- За час: 360 вызовов

**Пакетный подход:**
- 1 пакетный вызов / 30 секунд = 2 вызова API в минуту
- За час: 120 вызовов
- **Снижение стоимости на 66%!**

### Поток работы
```
1. Срабатывает таймер (30 секунд)
   ↓
2. Пакетный генератор формирует промпт
   ↓
3. Один вызов LLM генерирует все реплики NPC
   ↓
4. Парсинг JSON-ответа
   ↓
5. Обновление кэша менеджера состояний
   ↓
6. Клиент Godot периодически запрашивает статусы
```

## Описание конфигурации

### config.py
```python
# Интервал обновления NPC (в секундах)
NPC_UPDATE_INTERVAL = 30

# Настройки LLM
OPENAI_MODEL = "gpt-4o-mini"  # рекомендуется mini-версия для экономии
```

### Настройка частоты обновления
Измените `NPC_UPDATE_INTERVAL` в `config.py`:
- Разработка и тестирование: 10 секунд
- Боевой режим: 30-60 секунд
- Режим экономии: 120 секунд

## Поиск и устранение неполадок

### Проблема 1. Сбой запуска
```
❌ Не удалось инициализировать LLM
```
**Решение:** проверьте, что переменная OPENAI_API_KEY установлена.

### Проблема 2. NPC не отвечает
```
⚠️ Будет использоваться режим заготовленных диалогов
```
**Решение:** система автоматически переключается на заготовленные диалоги — базовый функционал не нарушается.

### Проблема 3. Ошибка CORS
**Решение:** проверьте параметр `CORS_ORIGINS` в `config.py`.

## Рекомендации по разработке

### Добавление нового NPC
1. Добавьте конфигурацию в `NPC_ROLES` в `agents.py`
2. Добавьте заготовленные диалоги в `preset_dialogues` в `batch_generator.py`
3. Перезапустите сервис

### Настройка стиля диалога
Отредактируйте функцию `create_system_prompt` в `agents.py`.

### Настройка промпта пакетной генерации
Отредактируйте функцию `_build_batch_prompt` в `batch_generator.py`.
