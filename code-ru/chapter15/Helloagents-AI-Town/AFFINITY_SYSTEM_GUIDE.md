# Руководство по системе симпатии NPC

## Обзор

Теперь NPC кибер-городка обладают **системой симпатии**: они автоматически корректируют уровень симпатии в зависимости от содержания диалога с игроком, что влияет на стиль и тон последующих разговоров!

---

## Ключевые возможности

### 1. **Автоматический анализ эмоций**
- Использование LLM-агента для анализа эмоций диалога
- Определение настроя игрока (дружелюбный / нейтральный / недружелюбный)
- Оценка качества диалога (содержательный / обычный / поверхностный)
- Распознавание эмоциональной окраски (похвала / критика / нейтральная)

### 2. **Динамическая корректировка симпатии**
- Дружелюбные диалоги повышают симпатию (от +1 до +10)
- Критические диалоги снижают симпатию (от -3 до -15)
- Автоматическое обновление значения симпатии (0-100)
- Ограничение в разумных пределах

### 3. **Система уровней отношений**
- **Незнакомец** (0-20): холодная отстранённость, мало готов общаться
- **Знакомый** (20-40): вежливо, но сухо
- **Дружелюбный** (40-60): вежливо и доброжелательно, обычное общение
- **Близкий** (60-80): дружелюбен и приветлив, охотно беседует
- **Близкий друг** (80-100): очень тёплое отношение, как у старых друзей

### 4. **Адаптация стиля диалога**
- Симпатия влияет на стиль речи NPC
- Высокая симпатия: больше энтузиазма, готовность делиться
- Низкая симпатия: сдержанность, короткие ответы
- Динамическая адаптация в реальном времени

## Примеры использования

### Пример 1. Рост симпатии

```
Начальная симпатия: 50 (дружелюбный)

Первый диалог:
Игрок: «Привет, рад познакомиться!»
Иван: «Привет! Я тоже рад знакомству.»
📈 Симпатия: 50 -> 55 (дружеское приветствие)

Второй диалог:
Игрок: «У тебя отличный код!»
Иван: «Спасибо! Я как раз изучаю новые технологии, тебе это интересно?»
📈 Симпатия: 55 -> 63 (похвала работы) → повышение уровня: дружелюбный -> близкий

Третий диалог:
Игрок: «А можешь меня научить?»
Иван: «Конечно! С удовольствием поделюсь. С чего хочешь начать?»
📈 Симпатия: 63 -> 69 (просьба об обучении)
```

### Пример 2. Снижение симпатии

```
Текущая симпатия: 69 (близкий)

Критический диалог:
Игрок: «Этот твой код — просто ужас!»
Иван: «Извини, я постараюсь исправить...»
📉 Симпатия: 69 -> 61 (критика работы) → снижение уровня: близкий -> дружелюбный
```

### Пример 3. Изменение стиля диалога

```
Симпатия: 30 (знакомый)
Игрок: «Привет, как дела?»
Пётр: «Нормально.» (короткий ответ)

Симпатия: 70 (близкий)
Игрок: «Привет, как дела?»
Пётр: «Отлично! Сейчас занимаюсь очень интересным проектом, рассказать?» (с энтузиазмом и подробно)

Симпатия: 90 (близкий друг)
Игрок: «Привет, как дела?»
Пётр: «Ха-ха, старина! Замотался по уши, но всё круто. Кстати, по тому твоему вопросу — я нашёл ответ!» (тепло и инициативно)
```

## Техническая реализация

### Архитектура

```
RelationshipManager
├── affinity_scores: Dict[str, Dict[str, float]]  # Хранилище симпатий NPC
├── analyzer_agent: SimpleAgent                   # Агент анализа эмоций
├── get_affinity(npc_name, player_id)            # Получить симпатию
├── analyze_and_update_affinity(...)             # Проанализировать и обновить симпатию
├── get_affinity_level(affinity)                 # Получить уровень отношений
└── get_affinity_modifier(affinity)              # Получить модификатор стиля диалога
```

### Процесс анализа эмоций

```
1. Игрок отправляет сообщение
   ↓
2. NPC формирует ответ
   ↓
3. Агент анализа эмоций обрабатывает диалог
   ├── Анализ настроя игрока
   ├── Оценка содержания диалога
   ├── Определение эмоциональной окраски
   └── Расчёт изменения симпатии
   ↓
4. Обновление симпатии
   ├── Текущее значение + изменение
   ├── Ограничение диапазоном 0-100
   └── Проверка смены уровня
   ↓
5. Сохранение в системе памяти
   └── Запись информации о симпатии и эмоциях
```

### Правила изменения симпатии

| Тип диалога | Изменение | Пример |
|-------------|-----------|--------|
| Похвала, благодарность, просьба | от +3 до +8 | «Ты молодец!» «Спасибо!» «Научи меня» |
| Дружеское приветствие, обычное общение | от +1 до +3 | «Привет!» «Как дела?» |
| Обычная болтовня, нейтральная тема | 0 | «Сегодня хорошая погода» |
| Критика, сомнения, раздражение | от -3 до -8 | «Это не очень» «Правда?» |
| Оскорбления, агрессия, злонамеренность | от -8 до -15 | «Ты бесполезен!» |

## Конфигурация системы симпатии

### Промпт для анализа эмоций

Агент анализа эмоций использует тщательно подготовленный промпт:

```python
[Аспекты анализа]
1. Настрой игрока: дружелюбный / нейтральный / недружелюбный
2. Содержание диалога: позитивное / нейтральное / негативное
3. Качество взаимодействия: глубокое / обычное / поверхностное
4. Эмоциональная окраска: похвала / критика / нейтральная

[Формат вывода]
{
    "should_change": true/false,
    "change_amount": целое число от -15 до +10,
    "reason": "краткое объяснение причины",
    "sentiment": "positive/neutral/negative"
}
```

### Рекомендации по настройке

Чтобы изменить чувствительность системы симпатии, отредактируйте промпт в `relationship_manager.py`:

- **Чувствительнее**: расширьте диапазон (например, от -20 до +15)
- **Консервативнее**: сузьте диапазон (например, от -5 до +5)
- **Тоньше**: добавьте больше аспектов анализа
- **Проще**: упростите правила анализа

## Частые вопросы

### Q1. Почему симпатия не меняется?

**Возможные причины:**
- Слишком нейтральное содержание диалога
- Агент анализа считает, что менять не нужно
- Не удалось распарсить ответ LLM

**Решения:**
- Используйте более явные эмоциональные выражения
- Проверьте результат анализа в логе
- Скорректируйте промпт анализа эмоций

### Q2. Симпатия меняется слишком быстро / медленно?

**Решения:**
- Измените диапазон изменения в `relationship_manager.py`
- Скорректируйте правила в промпте анализа
- Используйте `set_npc_affinity` для ручной установки начального значения

### Q3. Стиль диалога не меняется заметно?

**Возможные причины:**
- Слишком малая разница в значениях симпатии
- В `system_prompt` NPC недостаточно используется модификатор симпатии

**Решения:**
- Увеличьте разницу (например, 20 против 80)
- Подчеркните в `system_prompt` важность стиля диалога
