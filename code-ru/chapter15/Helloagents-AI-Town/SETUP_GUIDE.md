# Кибер-городок — Руководство по установке и настройке

## Системные требования

- **Операционная система:** Windows 10/11, macOS, Linux
- **Godot:** 4.2+ (рекомендуется 4.3)
- **Python:** 3.10+
- **Git:** (опционально, для клонирования проекта)

## Шаги установки

### Шаг 1. Загрузка проекта

**Способ A: через Git**
```bash
git clone https://github.com/datawhalechina/hello-agents
cd chapter15
```

**Способ B: загрузка ZIP**
1. Скачайте ZIP-архив проекта
2. Распакуйте его в любую директорию

### Шаг 2. Установка Godot

1. Откройте [официальный сайт Godot](https://godotengine.org/download)
2. Скачайте Godot версии 4.2+
3. Распакуйте и запустите Godot

### Шаг 3. Настройка Python-окружения

#### 3.1 Создание виртуального окружения
```bash
cd backend
python -m venv venv
```

#### 3.2 Активация виртуального окружения
**Windows:**
```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

#### 3.3 Установка зависимостей
```bash
pip install -r requirements.txt
```

#### 3.4 Установка HelloAgents
```bash
cd ../HelloAgents
pip install -e .
cd ../backend
```

### Шаг 4. Настройка переменных окружения

#### 4.1 Скопируйте файл с переменными окружения
```bash
cp .env.example .env
```

#### 4.2 Отредактируйте файл .env
```env
# Настройки API
API_HOST=0.0.0.0
API_PORT=8000

# Настройки LLM — пропишите свой ключ API
LLM_API_KEY=sk-your-api-key-here
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4

# Интервал обновления NPC (в секундах)
NPC_UPDATE_INTERVAL=30
```

**Важно:** замените `LLM_API_KEY` на ваш реальный API-ключ!

### Шаг 5. Запуск бэкенд-сервиса

```bash
cd backend
python main.py
```

**Ожидаемый вывод:**
```
📝 Файл логов диалогов: .../backend/logs/dialogue_2025-10-15.log
📂 Директория логов: .../backend/logs

============================================================
🎮 Бэкенд-сервис кибер-городка запускается...
============================================================
...
✅ Все сервисы запущены!
📡 Адрес API: http://0.0.0.0:8000
📚 Документация API: http://0.0.0.0:8000/docs
============================================================
```

### Шаг 6. Открытие проекта в Godot

1. Запустите Godot
2. Нажмите «Импорт»
3. Выберите `Helloagents-AI-Town/helloagents-ai-town/scenes/main.tscn`
4. Нажмите «Импортировать и редактировать»

### Шаг 7. Запуск игры

1. В редакторе Godot нажмите кнопку «Запустить» в правом верхнем углу (или клавишу F5)
2. Откроется окно игры
3. Используйте WASD для перемещения, клавишу E для взаимодействия с NPC

## Управление в игре

- **WASD** — перемещение игрока
- **E** — взаимодействие с NPC
- **Enter** — отправить сообщение
- **ESC** — закрыть окно диалога

## Частые вопросы

### Q1. Бэкенд не запускается?
**A:** Проверьте:
1. Версию Python (>=3.10)
2. Активировано ли виртуальное окружение
3. Установлены ли все зависимости
4. Корректность файла .env

### Q2. Godot не открывает проект?
**A:** Проверьте:
1. Версию Godot (>=4.2)
2. Существует ли файл project.godot
3. Правильно ли выбрана директория

### Q3. Игра запускается, но диалоги не работают?
**A:** Проверьте:
1. Запущен ли бэкенд-сервис
2. Правильный ли адрес бэкенда (по умолчанию http://localhost:8000)
3. Сообщения об ошибках в консоли Godot
