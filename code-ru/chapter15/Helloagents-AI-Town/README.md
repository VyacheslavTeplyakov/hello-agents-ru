# Кибер-городок — Система диалогов с ИИ-NPC

Имитация ИИ-городка на основе фреймворка HelloAgents, демонстрирующая применение мультиагентных систем в играх.

## Игровые возможности

- 3 ИИ-NPC (Иван, Пётр, Сергей)
- Система интеллектуальных диалогов
- Система памяти (краткосрочная + долгосрочная)
- Система симпатии (5 уровней отношений)
- Самостоятельное поведение NPC (прогулки, работа)
- Полноценная система логирования

## Технологический стек

- **Игровой движок:** Godot 4.x
- **Бэкенд-фреймворк:** FastAPI + Python 3.10+
- **ИИ-фреймворк:** HelloAgents
- **LLM:** OpenAI GPT-4 (поддерживаются и другие LLM-сервисы)
