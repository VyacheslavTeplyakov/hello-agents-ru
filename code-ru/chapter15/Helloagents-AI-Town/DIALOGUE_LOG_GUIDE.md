# Руководство по системе логов диалогов

## Обзор

Чтобы учащимся было удобнее изучать и анализировать диалоги NPC, реализована полноценная система логирования, которая одновременно выводит все сведения о диалогах:
- **В консоль** — для просмотра в реальном времени
- **В файл журнала** — для долговременного хранения и последующего анализа

---

## Возможности

### 1. Автоматическая запись сведений о диалоге

Система логов автоматически фиксирует:
- Начало и конец диалога
- Сообщения игрока
- Текущую симпатию и уровень отношений
- Извлечённые релевантные воспоминания
- Содержание ответов NPC
- Анализ изменения симпатии
- Смену уровня отношений
- Подтверждение сохранения в памяти

### 2. Двойной вывод

- **Консоль** — для отладки в реальном времени
- **Файл** — для последующего анализа и обзора

### 3. Группировка по датам

Файлы логов автоматически разделяются по датам:
```
backend/logs/
├── dialogue_2025-01-15.log
├── dialogue_2025-01-16.log
└── dialogue_2025-01-17.log
```

## Способы использования

### Способ 1. Запуск бэкенда (автоматическая запись)

```bash
cd code/chapter15/backend
python main.py
```

**Логи автоматически пишутся:**
- В консоль (показ в реальном времени)
- В `logs/dialogue_YYYY-MM-DD.log` (на диск)

**При запуске показывается путь к файлу логов:**
```
📝 Файл логов диалогов: D:\code\...\backend\logs\dialogue_2025-01-15.log
📂 Директория логов: D:\code\...\backend\logs
```

---

### Способ 2. Просмотр файла логов в реальном времени

**Запустите в другом окне терминала:**
```bash
cd code/chapter15/backend
python view_logs.py tail
```

**Эффект:**
- Содержимое логов отображается в реальном времени (аналог `tail -f`)
- Новые диалоги появляются мгновенно
- Остановка по `Ctrl+C`

---

### Способ 3. Просмотр полного лога

```bash
cd code/chapter15/backend
python view_logs.py view
```

**Эффект:**
- Показывает полное содержимое логов за сегодня
- Все диалоги выводятся за один раз

---

### Способ 4. Список всех файлов логов

```bash
cd code/chapter15/backend

```

**Эффект:**

## Учебная ценность

### 1. Полная визуализация диалога

Учащимся хорошо видно:
- Ввод игрока
- Процесс извлечения воспоминаний
- Формирование ответа NPC
- Анализ симпатии
- Сохранение в памяти

### 2. Проверка системы симпатии

- Видно, как симпатия меняется в зависимости от диалога
- Понятен результат анализа эмоций
- Наблюдается смена уровня отношений

### 3. Проверка системы памяти

- Видно, какие воспоминания извлекает NPC
- Понятно, как память влияет на диалог
- Подтверждается успешное сохранение

### 4. Отладка и оптимизация

- Быстрая локализация проблем
- Анализ качества диалогов
- Настройка параметров системы

## Техническая реализация

### Ядро logger.py

```python
# Создаём logger
dialogue_logger = logging.getLogger("dialogue")

# Файловый handler — запись в файл
file_handler = logging.FileHandler(LOG_FILE, encoding="utf-8")

# Консольный handler — вывод в консоль
console_handler = logging.StreamHandler()

# Добавляем handlers
dialogue_logger.addHandler(file_handler)
dialogue_logger.addHandler(console_handler)
```

### Интеграция в agents.py

```python
from logger import (
    log_dialogue_start, log_affinity, log_memory_retrieval,
    log_generating_response, log_npc_response, log_analyzing_affinity,
    log_affinity_change, log_memory_saved, log_dialogue_end
)

def chat(self, npc_name: str, message: str, player_id: str = "player") -> str:
    # Записываем начало диалога
    log_dialogue_start(npc_name, message)
    
    # Записываем симпатию
    log_affinity(npc_name, affinity, affinity_level)
    
    # Записываем извлечение воспоминаний
    log_memory_retrieval(npc_name, len(relevant_memories), relevant_memories)
    
    # Записываем ответ NPC
    log_npc_response(npc_name, response)
    
    # Записываем изменение симпатии
    log_affinity_change(affinity_result)
    
    # Записываем завершение диалога
    log_dialogue_end()
```

## Частые вопросы

### Q1. Где лежат файлы логов?

**A:** Файлы логов сохраняются в директории `backend/logs/` с именами по датам:
```
backend/logs/dialogue_YYYY-MM-DD.log
```

При запуске бэкенда полный путь к файлу выводится в консоль.

---

### Q2. Как смотреть логи в реальном времени?

**A:** Есть два способа.

**Способ 1. Смотреть вывод в консоли**
```bash
cd code/chapter15/backend
python main.py
```

**Способ 2. Использовать утилиту просмотра**
```bash
# В другом окне терминала
cd code/chapter15/backend
python view_logs.py tail
```

---

### Q3. Не займут ли логи много места?

**A:** Нет. Файлы делятся по датам, по одному файлу на день. Обычно:
- На один диалог приходится 0.5-1 КБ
- 100 диалогов — около 50-100 КБ
- За день обычно не больше 1 МБ

---

### Q4. Можно ли смотреть старые логи?

**A:** Да! Используйте команды:

```bash
# Список всех файлов логов
python view_logs.py list

# Просмотр логов за нужную дату
python view_logs.py view
```

Либо просто откройте файл вручную:
```
backend/logs/dialogue_2025-01-15.log
```

### Преимущества

1. **Двойной вывод** — консоль и файл, удобно и в реальном времени, и для последующего просмотра
2. **Автоматическая запись** — никаких ручных действий, всё пишется само
