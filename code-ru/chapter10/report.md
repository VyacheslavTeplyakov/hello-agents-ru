# Исследовательский отчёт по фреймворкам AI-агентов

## Введение
Данный отчёт посвящён исследованию проектов, связанных с AI-агентами, на GitHub. Анализ особенностей и функций этих проектов призван помочь разработчикам лучше ориентироваться при выборе подходящего фреймворка для AI-агентов.

## Основные результаты

1. **Flowise**
   - **Описание**: Build AI Agents, Visually
   - **Особенности**: Предоставляет визуальный интерфейс, позволяющий пользователям легко создавать AI-агентов без необходимости писать большой объём кода.

2. **activepieces**
   - **Описание**: AI Agents & MCPs & AI Workflow Automation • (~400 MCP servers for AI agents) • AI Automation / AI Agent with MCPs • AI Workflows & AI Agents • MCPs for AI Agents
   - **Особенности**: Поддерживает интеграцию AI-агентов и MCP-серверов (многооблачных платформ), предоставляет богатый набор автоматизированных рабочих процессов и функций агентов.

3. **AgentGPT**
   - **Описание**: 🤖 Assemble, configure, and deploy autonomous AI Agents in your browser.
   - **Особенности**: Позволяет пользователям собирать, настраивать и развёртывать автономных AI-агентов прямо в браузере, обеспечивая высокую гибкость и простоту использования.

4. **ai-agents-for-beginners**
   - **Описание**: 12 Lessons to Get Started Building AI Agents
   - **Особенности**: Разработан для начинающих, предлагает 12 уроков, помогающих новичкам быстро освоить разработку AI-агентов.

5. **ai**
   - **Описание**: The AI Toolkit for TypeScript. From the creators of Next.js, the AI SDK is a free open-source library for building AI-powered applications and agents
   - **Особенности**: Разработан создателями Next.js, поддерживает TypeScript, является бесплатной библиотекой с открытым исходным кодом для создания приложений и агентов на базе ИИ.

## Заключение
Общей чертой этих проектов является предоставление богатого набора инструментов и ресурсов, помогающих разработчикам создавать AI-агентов и управлять ими. Будь то визуальный интерфейс, инструменты настройки в браузере, подробные руководства или мощный SDK — все эти проекты значительно упрощают процесс разработки AI-агентов. Для разработчиков разного уровня подготовки эти проекты предлагают соответствующую поддержку: от новичков до опытных пользователей каждый найдёт подходящий инструмент.
