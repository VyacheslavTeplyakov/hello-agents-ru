# Контрольный список публикации

Перед отправкой на Smithery убедитесь, что все пункты ниже выполнены:

## Проверка файлов

- [ ] README.md полный и понятный
- [ ] Файл LICENSE присутствует
- [ ] Dockerfile настроен корректно (рекомендуется)
- [ ] pyproject.toml настроен корректно (обязательно)
- [ ] requirements.txt содержит все зависимости
- [ ] smithery.yaml настроен корректно
- [ ] server.py запускается нормально

## Функциональное тестирование

- [ ] Сервер запускается нормально
- [ ] Все инструменты вызываются корректно
- [ ] Обработка ошибок реализована
- [ ] Формат возвращаемых результатов корректен

## Проверка документации

- [ ] Инструкции по установке понятны
- [ ] Примеры использования полные
- [ ] Документация API подробная
- [ ] Список поддерживаемых функций полный

## Проверка конфигурации

- [ ] name и version в pyproject.toml корректны
- [ ] name в smithery.yaml уникален
- [ ] version в pyproject.toml и smithery.yaml совпадают
- [ ] version соответствует семантическому версионированию
- [ ] Список tools полный
- [ ] URL homepage корректен

## Подготовка GitHub

- [ ] Код отправлен на GitHub
- [ ] Создан тег v1.0.0
- [ ] Создан Release
- [ ] Репозиторий публичный

## Финальная проверка

- [ ] Локальное тестирование пройдено
- [ ] В документации нет опечаток
- [ ] Все ссылки доступны
- [ ] Готово к отправке на Smithery

## Шаги для отправки

1. Перейдите на https://smithery.ai/
2. Войдите через GitHub
3. Нажмите "Submit Server"
4. Введите URL репозитория
5. Подтвердите информацию и отправьте
6. Ожидайте проверки (1–3 дня)

## После проверки

- [ ] Получено письмо об успешном прохождении проверки
- [ ] Сервер доступен для поиска на Smithery
- [ ] Протестирована установка и использование
- [ ] Поделились с сообществом
