## Быстрый старт

### Подготовка окружения

1. **Установка фреймворка HelloAgents**:
   ```bash
   pip install hello-agents[evaluation]==0.2.3
   ```

2. **Настройка переменных окружения**:
   ```bash
   # OpenAI API Key (для GPT-4o)
   export OPENAI_API_KEY="your_openai_api_key"
   
   # HuggingFace Token (для датасета GAIA)
   export HF_TOKEN="your_huggingface_token"
   ```

3. **Загрузка датасета BFCL** (опционально, при первом запуске загружается автоматически):
   ```bash
   cd ../HelloAgents
   git clone https://github.com/ShishirPatil/gorilla.git temp_gorilla
   ```

### Запуск примеров

#### 1. Базовый пример агента

```bash
python 01_basic_agent_example.py
```

Этот пример демонстрирует базового ReAct-агента и объясняет, почему нужна система оценки.

#### 2. Быстрый старт BFCL

```bash
python 02_bfcl_quick_start.py
```

Самый простой способ оценки BFCL — одна строка кода.

**Ожидаемый вывод**:
```
Точность: 100.00%
Правильных: 5/5
```

#### 3. Кастомная оценка BFCL

```bash

```

Показывает, как использовать низкоуровневые компоненты для кастомного цикла оценки.

#### 4. Лучшие практики BFCL

3. Дождитесь одобрения (обычно 1–2 дня)

## Часто задаваемые вопросы

### В1: При запуске примеров выдаётся ошибка «модуль не найден»?

О: Убедитесь, что фреймворк HelloAgents установлен:
```bash
cd ../HelloAgents
pip install -e .
```

### В2: При оценке BFCL выдаётся ошибка «датасет не найден»?

О: При первом запуске датасет скачивается автоматически — проверьте подключение к интернету. Если скачивание не удаётся, можно скачать вручную:
```bash
cd ../HelloAgents
git clone https://github.com/ShishirPatil/gorilla.git temp_gorilla
```

### В3: При оценке GAIA выдаётся ошибка «нет доступа»?

О: GAIA — закрытый датасет, для доступа необходимо подать заявку:
1. Перейдите на https://huggingface.co/datasets/gaia-benchmark/GAIA
2. Нажмите «Request Access»
3. Дождитесь одобрения
4. Задайте переменную окружения HF_TOKEN

### В4: Оценка выполняется слишком медленно?

О: Уменьшите количество образцов:
```python
# Оценка BFCL
results = bfcl_tool.run(agent, category="simple_python", max_samples=5)

# Оценка GAIA
results = gaia_tool.run(agent, level=1, max_samples=2)

# Оценка генерации данных
python 07_data_generation_complete_flow.py 10 3.0  # только 10 задач
```

### В5: Как оценить стоимость оценки?

О: Основная стоимость — вызовы LLM API:

**Оценка BFCL**:
- Около 1 вызова API на образец
- Стоимость около 0,01–0,02 руб./образец
- Полная оценка (400 образцов) — около 4–8 руб.

**Оценка GAIA**:
- Около 1–5 вызовов API на образец (зависит от сложности задачи)
- Стоимость около 0,05–0,20 руб./образец
- Полная оценка (466 образцов) — около 23–93 руб.

**Оценка генерации данных**:
- Генерация: около 0,05 руб./задача
- LLM Judge: около 0,02 руб./задача
- Win Rate: около 0,02 руб./сравнение
- Генерация 30 задач — около 2–3 руб.
