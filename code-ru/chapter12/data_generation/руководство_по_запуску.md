# Полное руководство по запуску генерации и оценки данных AIME

В данном документе приведены полные пошаговые инструкции — от генерации данных до создания отчёта по оценке.

## Предварительные требования

### 1. Настройка окружения

Убедитесь, что все зависимости установлены:

```bash
# Установка зависимостей системы оценки
pip install hello-agents[evaluation]

# Или ручная установка
pip install datasets huggingface_hub pandas tqdm gradio
```

### 2. Настройка переменных окружения

Задайте в файле `.env`:

```bash
# API-ключ LLM (один из вариантов)
DASHSCOPE_API_KEY=your_dashscope_key  # Alibaba Cloud DashScope
OPENAI_API_KEY=your_openai_key        # OpenAI

# Токен HuggingFace (для загрузки датасетов)
HF_TOKEN=your_hf_token
```

## Полные шаги запуска

### Шаг 1: Запуск полного цикла оценки

Это **однокомандный** способ — автоматически выполняет генерацию, оценку и создание отчёта:

```bash
cd docs/chapter12/HelloAgents
python data_generation/run_complete_evaluation.py 30 3.0
```

**Описание параметров**:
- `30` — сгенерировать 30 задач
- `3.0` — интервал между генерациями 3 секунды (рекомендуется 2–3 секунды)

**Примечание**:
- В качестве референса для оценки используются реальные задачи AIME 2025 года
- Источник датасета: math-ai/aime25 (формат JSONL)

**Ориентировочное время**:
- Генерация 30 задач: примерно 15–30 минут (зависит от скорости API)
- Оценка LLM Judge: примерно 10–15 минут
- Оценка Win Rate: примерно 5–10 минут
- **Итого**: примерно 30–55 минут

**Выходные файлы**:
```
data_generation/
├── generated_data/
│   └── aime_generated_YYYYMMDD_HHMMSS.json  # сгенерированные задачи
└── evaluation_results/
    └── YYYYMMDD_HHMMSS/
        ├── llm_judge/
        │   ├── llm_judge_result_YYYYMMDD_HHMMSS.jsonl
        │   └── llm_judge_report_YYYYMMDD_HHMMSS.md
        ├── win_rate/
        │   ├── win_rate_result_YYYYMMDD_HHMMSS.jsonl
        │   └── win_rate_report_YYYYMMDD_HHMMSS.md
        └── comprehensive_report.md  # сводный отчёт
```

### Шаг 2: Просмотр отчётов по оценке

#### 2.1 Просмотр сводного отчёта

```bash
# Найти последнюю директорию с результатами
cd data_generation/evaluation_results
ls -lt  # посмотреть самую новую директорию

# Просмотреть сводный отчёт
cat YYYYMMDD_HHMMSS/comprehensive_report.md
```

**Сводный отчёт содержит**:
- Основную информацию (время генерации, количество задач и т. д.)
- Статистику генерации данных (распределение по темам, анализ ответов)
- Результаты оценки LLM Judge (общий балл, баллы по измерениям)
- Результаты оценки Win Rate (статистика побед, сравнительный анализ)
- Общий вывод и рекомендации по улучшению

#### 2.2 Просмотр детальных отчётов

**Детальный отчёт LLM Judge**:
```bash
cat YYYYMMDD_HHMMSS/llm_judge/llm_judge_report_YYYYMMDD_HHMMSS.md
```

**Детальный отчёт Win Rate**:
```bash
cat YYYYMMDD_HHMMSS/win_rate/win_rate_report_YYYYMMDD_HHMMSS.md
```

### Шаг 3: Ручная верификация (опционально)

Если требуется ручная верификация, запустите:

```bash
python data_generation/human_verification_ui.py data_generation/generated_data/aime_generated_YYYYMMDD_HHMMSS.json
```

**Порядок работы**:
1. Браузер автоматически откроется на `http://127.0.0.1:7860`
2. Прочитайте условие задачи, ответ и решение
3. Выставьте оценки по 4 параметрам (по 1–5 баллов)
4. Выберите статус верификации (approved/rejected/needs_revision)
5. Добавьте комментарии (опционально)
6. Нажмите «Подтвердить верификацию»
7. Перейдите к следующей задаче

**Результаты верификации сохраняются в**:
```
data_generation/generated_data/aime_generated_YYYYMMDD_HHMMSS_verifications.json
```

## Пошаговый запуск (продвинутый режим)

Если нужно запускать по шагам, следуйте инструкциям ниже:

### Шаг 1: Только генерация данных

```python
from data_generation.aime_generator import AIMEGenerator

generator = AIMEGenerator(delay_seconds=3.0)
generated_data_path = generator.generate_and_save(num_problems=30)
print(f"Данные сохранены в: {generated_data_path}")
```

### Шаг 2: Только оценка LLM Judge

```python
from hello_agents import HelloAgentsLLM
from hello_agents.tools import LLMJudgeTool

llm = HelloAgentsLLM()
llm_judge_tool = LLMJudgeTool(llm=llm)

result = llm_judge_tool.run({
    "generated_data_path": "data_generation/generated_data/aime_generated_XXXXXX.json",
    "reference_year": 2025,
    "max_samples": 30,
    "output_dir": "data_generation/evaluation_results/llm_judge"
})
```

### Шаг 3: Только оценка Win Rate

```python
from hello_agents import HelloAgentsLLM
from hello_agents.tools import WinRateTool

llm = HelloAgentsLLM()
win_rate_tool = WinRateTool(llm=llm)

result = win_rate_tool.run({

    "reference_year": 2025,
    "num_comparisons": 20,
    "output_dir": "data_generation/evaluation_results/win_rate"
})
```

## Часто задаваемые вопросы

### 1. Ограничение скорости API

**Проблема**:
```
INFO:openai._base_client:Retrying request to /chat/completions in 0.451826 seconds
```

**Решение**:
- Увеличьте задержку: `python data_generation/run_complete_evaluation.py 30 5.0`
- Используйте восстановление из чекпоинта: после прерывания повторный запуск той же команды автоматически продолжит с места остановки

### 2. Медленная загрузка с HuggingFace

**Проблема**: медленная загрузка датасета AIME

**Решение**:
```bash
# Использовать зеркало
export HF_ENDPOINT=https://hf-mirror.com

# Или скачать вручную и использовать локальный путь
```

### 3. Повторяющиеся задачи

**Проблема**: сгенерированные задачи повторяются

**Решение**:
- Уже используется 900+ реальных задач как примеры-референсы
- Каждый раз случайно выбирается разный референс
- Промпт явно требует «сгенерировать полностью другую задачу»

### 4. Ошибка оценки

**Проблема**: оценка LLM Judge или Win Rate завершается с ошибкой

**Решение**:
- Проверьте правильность API-ключа
- Убедитесь, что файл с данными существует
- Проверьте корректность формата файла данных

## Стандарты качества

### Отличное качество
- Средний балл LLM Judge ≥ 4.5/5.0
- Win Rate ≥ 48% (близко к 50%)
- Доля прошедших ≥ 90%
- Доля прошедших ручную верификацию ≥ 95%

### Хорошее качество
- Средний балл LLM Judge ≥ 4.0/5.0
- Win Rate ≥ 45%
- Доля прошедших ≥ 80%
- Доля прошедших ручную верификацию ≥ 90%

### Требует улучшения
- Средний балл LLM Judge < 4.0/5.0
- Win Rate < 45%
- Доля прошедших < 80%
- Доля прошедших ручную верификацию < 90%

## Следующие шаги

В зависимости от результатов оценки:

1. **Если качество отличное**:
   - Можно использовать сгенерированные данные
   - Рассмотрите генерацию большего объёма данных
   - Сохраните отчёт по оценке как подтверждение качества

2. **Если качество хорошее**:
   - Проведите ручную верификацию
   - Отберите данные высокого качества
   - Скорректируйте промпты генерации

3. **Если требует улучшения**:
   - Проанализируйте общие проблемы задач с низким баллом
   - Скорректируйте промпты генерации
   - Перегенерируйте и оцените повторно
