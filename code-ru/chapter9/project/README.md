# Демонстрационная директория проекта

Эта директория используется для демонстрации функций безопасности TerminalTool.

## Описание

TerminalTool обладает следующими функциями безопасности:

1. **Белый список команд**: разрешено выполнять только определённые безопасные команды
2. **Ограничение рабочей директории**: нельзя получить доступ к файлам вне рабочей директории
3. **Защита от выхода за пределы пути**: предотвращает выход из рабочей директории через `..` и подобные приёмы

## Тестовые сценарии

- Попытка выполнить опасную команду (например, `rm -rf`) будет заблокирована
- Попытка получить доступ к файлам вне рабочей директории будет отклонена
- Попытка выйти из рабочей директории через относительный путь будет обнаружена и заблокирована
