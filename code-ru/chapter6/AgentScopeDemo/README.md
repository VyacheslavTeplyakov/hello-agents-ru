# AgentScope: «Троецарствие: Мафия»

В этом каталоге находится полный практический пример из шестой главы фреймворка AgentScope, демонстрирующий, как создать мультиагентную онлайн-игру с элементами классической китайской культуры.

## Файлы

- `main_cn.py` — основная логика игры и контроллер
- `prompt_cn.py` — управление промптами
- `game_roles.py` — определение и конфигурация игровых ролей
- `structured_output_cn.py` — модели структурированного вывода
- `utils_cn.py` — вспомогательные функции и методы
- `README.md` — этот документ

## Особенности примера

- **Архитектура на основе сообщений**: демонстрирует ключевой механизм передачи сообщений в AgentScope
- **Параллельное взаимодействие**: показывает, как несколько агентов работают в режиме реального времени
- **Ролевая игра**: каждый агент имеет двойную идентичность (игровая роль + персонаж «Троецарствия»)
- **Структурированный вывод**: ограничения поведения агентов через Pydantic-модели
- **Устойчивость к ошибкам**: сбой отдельного агента не влияет на общий ход игры

## Подготовка окружения

### 1. Установка зависимостей

```bash
pip install agentscope
pip install dashscope
pip install pydantic
```

### 2. Настройка переменных окружения

Установите ключ API DashScope от Alibaba Cloud:

```bash
# Linux/Mac
export DASHSCOPE_API_KEY="your-api-key-here"

# Windows PowerShell
$env:DASHSCOPE_API_KEY="your-api-key-here"

# Windows CMD
set DASHSCOPE_API_KEY=your-api-key-here
```

Получить ключ API: https://dashscope.console.aliyun.com/apiKey

### 3. Запуск игры

```bash
python main_cn.py
```

## Описание игровых ролей

### Игровые роли
- **Оборотень**: ночью убивает мирных, днём скрывает личность
- **Провидец**: каждую ночь проверяет личность одного игрока
- **Ведьма**: имеет одно противоядие и один яд
- **Охотник**: при выбывании по голосованию может застрелить одного игрока
- **Крестьянин**: вычисляет оборотней с помощью логики и голосования

### Персонажи «Троецарствия»
- **Лю Бэй**: добросердечный, умеет объединять людей
- **Гуань Юй**: верный и решительный, прямолинеен
- **Чжан Фэй**: бесшабашный, легко вспыхивает
- **Чжугэ Лян**: несравненно мудр, точен в анализах
- **Цао Цао**: великий стратег, мастер интриг
- **Сыма И**: дальновидный мыслитель, скрытен

## Архитектура

### Слоистая архитектура
```
Уровень управления игрой (ThreeKingdomsWerewolfGame)
    ├── Управление состоянием
    ├── Управление ходом игры
    └── Определение победителя

Уровень взаимодействия агентов (MsgHub)
    ├── Маршрутизация сообщений
    ├── Параллельная обработка
    └── Синхронизация состояния

Уровень моделирования ролей (DialogAgent)
    ├── Промпты ролей
    ├── Структурированный вывод
    └── Ограничения поведения
```

### Основные компоненты

**1. Центр сообщений (MsgHub)**
```python
async with MsgHub(
    participants=self.werewolves,
    enable_auto_broadcast=True
) as hub:
    # Ночное обсуждение оборотней
    for wolf in self.werewolves:
        await wolf(structured_model=DiscussionModelCN)
```

**2. Структурированный вывод**
```python
class VoteModelCN(BaseModel):
    vote: str = Field(description="Имя игрока для голосования")
    reason: str = Field(description="Причина голосования")
    confidence: int = Field(ge=1, le=10, description="Уровень уверенности")
```

**3. Параллельный конвейер**
```python
vote_msgs = await fanout_pipeline(
    self.alive_players,
    msg=vote_announcement,
    structured_model=get_vote_model_cn(self.alive_players),
    enable_gather=False,
)
```

## Ход игры

### Ночная фаза
1. **Обсуждение оборотней**: оборотни договариваются о цели через MsgHub
2. **Проверка провидца**: провидец выбирает объект для проверки
3. **Действие ведьмы**: ведьма решает, применять ли противоядие / яд

### Дневная фаза
1. **Объявление смертей**: публикуется список погибших за ночь
2. **Свободное обсуждение**: все живые игроки участвуют в обсуждении
3. **Голосование**: выбирается игрок для исключения
4. **Способность охотника**: исключённый охотник может выстрелить

## Частые вопросы

### В: Игра не запускается?
О: Проверьте следующее:
- Убедитесь, что переменная окружения DASHSCOPE_API_KEY установлена
- Проверьте, что ключ API действителен
- Проверьте подключение к интернету

### В: Неверный формат вывода агента?
О: Возможные причины:
- Ограничения понимания модели
- Недостаточно чёткий промпт
- Слишком сложные ограничения структурированного вывода

### В: Ход игры завис?
О: Рекомендации:
- Проверьте передачу сообщений в MsgHub
- Проверьте состояние выполнения параллельного конвейера
- Изучите логи ошибок в консоли
